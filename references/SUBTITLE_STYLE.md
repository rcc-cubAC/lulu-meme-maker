# 中文字幕风格规范 v1

## 固定样式

- 字体：优先 Noto Sans CJK SC Bold（使用设备已安装字体；不含字体文件）。
- 字色：纯白 `#FFFFFF`。
- 描边：近黑 `#090909`，约为字高的 8–10%，圆润醒目。
- 位置：图像下方水平居中，距底边约 5–7% 图片高度，默认单行，太长时最多两行。
- 字号：随画面高度自适应，默认约占高的 7%，字过长时平滑缩小以保证文字完整。
- 字距：自然紧凑，不使用小字号日文字注音或繁杂动画字效。
- 不加半透明底条、不叠加水印、logo、播放器进度条、弹幕与无关文字。

## 文字不可变的核对范例

- 马噜：`曹贼`
- 袁公噜：`那就容我袁公噜告老还乡了`
- 邢道噜：`我乃是零陵上将军邢道噜`

涉及角色名字的替换必须完整逐字核对；尤其避免 `袁术`、`袁公噜`、`袁公噜老还乡`、`邢道荣` 与 `邢道噜` 混写。

## 为什么建议字幕后期生成

图像生成模型在中文长句、相近字和特殊角色名上可能出错；固定的后期脚本可以保证你提供的台词原样输出，并使多张表情包的字体、描边和底边距尽量统一。它只能添加字幕，不能自动识别或消除原来的字幕，请首先生成无文字的底图。

## 示例命令

```bash
python scripts/add_subtitle.py --input blank_ma.png --output ma.png --text '曹贼'
python scripts/add_subtitle.py --input blank_yuan.png --output yuan.png --text '那就容我袁公噜告老还乡了'
python scripts/add_subtitle.py --input blank_xing.png --output xing.png --text '我乃是零陵上将军邢道噜'
```
