# 成品核验表

生成后逐项检查；任一关键项失败时重做或编辑局部区域。

## 角色相似度（关键）

- [ ] 是否以用户原始噜噜参考图为准，主角明显属于同一个IP角色？
- [ ] 橙色脸部完整顺滑，**没有额外鼻孔/动物鼻子**？
- [ ] 大头、矮胖、**短手**与小圆爪是否保持？
- [ ] 眼睛的蓝色虹膜、黑瞳与高光是否清楚？
- [ ] 小耳朵与头顶橘子是否仍在？
- [ ] 是否没有写实人脸、真实水豚皮毛和成人手指？

## 镜头与剧情

- [ ] 是否保留原画面关键机位、表情、手势和历史服装？
- [ ] **头部朝向和眼神方向**是否分别符合要求？
- [ ] 铠甲是否按照短胖Q版身形贴合，肩膀是否自然？
- [ ] 宽幅、正方形或竖版画幅是否匹配用户意图？
- [ ] 是否只输出用户要求的独立图片，没有擅自拼成分镜或左右对照？

## 字幕与清理

- [ ] 台词是否与用户给定内容逐字一致（尤其“噜”字）？
- [ ] 字体是否统一为白色加粗、近黑粗描边、下方居中？
- [ ] 是否没有图像生成阶段带入的错字或双层字幕？
- [ ] 是否没有水印、弹幕、日文假名、应用控件与无关数字？
- [ ] 字体在浅色背景与复杂铠甲上是否清晰可读？

## 交付

- [ ] 是否有能正常打开的PNG（优先）？
- [ ] 是否以角色名和台词命名文件？
- [ ] 若多张，是否每张单独存储、分别链接？
